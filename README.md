고칠 때:
- 운영자 정보는 상호와 이메일만 적는다.
- 법령이 요구하는 항목만 짧게 쓰고, 내부 설비·보안에 관한 세부는 적지 않는다.
- 약관을 바꾸면 서버의 약관 버전(`TERMS_VERSION`)을 올려 앱에서 다시 동의를 받는다.
- 처리방침의 위탁·국외 이전 표에 없는 업체로 개인정보를 보내기 전에 표를 먼저 고친다.
